# Kingdoms & Dragons Traveler Edition — v89

Published September 26, 2026

## Changes since the previous live version

- Kept the bottom navigation fixed at the bottom of the screen.
- Moved the Journey map to the bottom of the Journey page.
- Removed the unfinished notification feature and the Customize Home button; the Home schedule and announcement panels can still be swapped.
- Show the full selected day's schedule on Home, with arrows beside the day number to move to the previous or next day. The date, announcement heading, and journey button follow the selected day.
- Show only the selected day's Xavier announcement on a Journey day. Empty announcement cards are hidden there.
- Updated the animated tutorial, instruction booklet, and interactive travel book for the current app.

The release was tested on the separate Kingdoms & Dragons test site before production publication.
