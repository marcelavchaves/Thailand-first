# Offline Snapshot

Available in More on live and prototype when enabled. TD Suitcase → Offline Snapshot controls whether travelers can create new copies. Hidden snapshots are unavailable from More and the PDF endpoint; signed-in TDs can still preview. Existing saved PDFs and device copies cannot be revoked.

The dated snapshot contains the calendar and day plans, published announcements, hotels and flights, three-column guest photo/name/hometown tiles, and reading guidance. It excludes Maps, Handouts, Gallery, trivia, language lessons, private safes, meal submissions and guest contact details.

Travelers can download the full PDF, select individual pages, save a page as a photo, or save it in the built-in reader. The reader supports swiping, zoom, linked contents/calendar, full-screen reading and remembering the last page. Save once online to cache the reader and PDF, then reopen offline. Refreshing a saved snapshot replaces it with the latest content; an unsuccessful refresh preserves the previous copy. Each page shows its download date and a warning that it may be out of date.

In More → Offline Snapshot, **Open Book** opens the saved copy. **Refresh Saved Snapshot** opens the reader and replaces its device copy with a freshly generated snapshot while online. The reader also has a prominent refresh button. PDF files previously downloaded to Files, Books or another reader are separate files; download a new PDF to replace those. A failed refresh preserves the saved book. TD visibility actions use large, high-contrast buttons and a clear shown/hidden status.
