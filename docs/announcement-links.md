# Links in TD announcements

In TD Suitcase → Announcements, edit the note, select the words to make clickable and choose **Add Link**. Enter the link address and select **Insert Link**. Review the Preview, then use **Post Note** to publish. Without a selection, enter the link text to insert at the cursor.

Use **Edit Or Remove Links** to change an existing link or turn it back into plain text. Existing announcements are retained without migration. Traveler links are underlined; web links open in a separate tab. Web, email and phone links are supported, with unsafe protocols rendered as plain text. WhatsApp shares, notification previews and offline snapshots use readable text and addresses.
